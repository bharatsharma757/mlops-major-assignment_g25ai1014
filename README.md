# ML Ops Major Assignment

End-to-end MLOps pipeline using the **Olivetti Faces Dataset** and **Decision Tree Classifier**.

## Features

* Model Training & Testing
* Git Branching Strategy (main, dev, docker_cicd)
* GitHub Actions CI/CD Pipeline
* Flask Web Application
* Docker Containerization
* Kubernetes Deployment with 3 Replicas
* Self-Healing Pod Recovery

## Model Details

* Dataset: Olivetti Faces
* Algorithm: DecisionTreeClassifier
* Train-Test Split: 70:30
* Accuracy: 53.33%

## Technologies Used

Python, Scikit-Learn, Flask, Git, GitHub Actions, Docker, Docker Hub, Kubernetes.
